# ruka.

**your words, your style.**

公開用の文体分析エディター。日本語の文章の文字数、平均文長、会話率、文長分布をiPhone Safariで確認できます。

## 使い方

GitHub Pagesを有効にしてから、公開URLで文章を貼り付けて「文体を分析」を押してください。結果は端末内で計算し、分析プリセットをローカル保存できます。外部生成APIやサーバーへの文章送信はありません。

## 公開フロー

- 非公開開発元: `al1ce4869999999-ux/ruka`
- このリポジトリは公開版の配信用。検証済みファイルのみ移す。
- 公開版にAPIキー、秘匿文書、ユーザー文章、未確認のテストデータを含めない。
- 現状は静的HTML。GitHub Pagesで `main` の `/(root)` を公開対象にする。
- GitHub上にファイルがあることと、Pagesで稼働していることは別。iPhone Safariで実機検証するまで動作確認済みとはしない。
